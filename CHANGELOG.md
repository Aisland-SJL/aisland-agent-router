## 0.1.0 - 2026-10-02

First public release.

- Main-conversation decisions with on-demand exploration, execution, expert advice, and independent review.
- Explicit squad requests and configurable passive triggers.
- Risk-based acceptance with evidence; historical run records retain their original validation rules.
- Scoped local token observations for the recorded main and child sessions, with incomplete snapshots and session totals clearly labeled.
- Single-frame numbered text recaps instead of aligned character tables.
- Standard-library configuration and record helpers, with 41 offline regression tests.

Known limits: Explorer Fast requires host support for role or speed selection and is not verified through the current native API. Logged model context is not backend attestation. This release does not estimate fees or savings.
