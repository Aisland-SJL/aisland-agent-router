# 原生子 Agent 协作

主会话承担决策与最终验收；按当前任务与已确认配置选择必要角色。接口以本次实际工具声明为准。

轻量路径与完整记录路径的选择见 [SKILL.md](../SKILL.md#轻量优先)。短小、低风险的一次交接不必加载本参考或创建运行记录；直接使用已知事实派单、验收并给简短复盘。本文件中的 JSON、UUID 和计量要求只适用于需要完整记录的任务。

## 派发与复用

创建子 Agent 时传必要消息、已授权 model 和 reasoning_effort，fork_context 默认 false。继续问题使用 send_input；关闭会话后需要延续可 resume_agent 再 send_input。需要结果时有界等待，完成但开放的会话也可能占并发名额。按配置与宿主上限较小者安排。

本机接口通常以 `multi_agent_v1__spawn_agent/send_input/wait_agent/close_agent/resume_agent` 暴露。不得用用户拥有的 create_thread 或跨聊天消息替代本任务子 Agent。

先决定主会话下一步，再派可以独立推进的工作；有独立工作就并行推进，没有则有界等待，不为避免等待额外制造任务。Executor 直接在授权文件范围实施，其他任务有不同写入归属。专家咨询只给问题需要的背景，延续同一问题优先复用，保留 id 和结论。

派单包含：目标与产物、必要来源和局部规则、读写边界、验收、停止条件。子任务自行选方法、保留他人修改、不派下级，返回产物、具体工作、检查证据及缺口。

## Explorer 的 Fast 请求

模板：`../assets/agents/aisland_explorer.toml`；个人入口：`~/.codex/agents/aisland_explorer.toml`；具名角色：`aisland_explorer`。模板请求 Luna medium Fast，默认只读；其他用户以自己的授权为准。

只有宿主提供 `agent_type` 或等价角色选择入口，或支持实际速度参数时，才能显式请求相应配置。只在提示词写角色名不算选择角色。核对模板、Skill 安装副本及个人入口与本地偏好一致；固定角色值可能覆盖派发参数。

没有选择或速度参数时明确标无法请求 Fast，不改变全局或主会话速度替代。配置保存、宿主加载、请求档位与实际服务是不同证据；后台未证明就标未验证。

## 审查与验收

用户要求审查或风险值得独立检查时使用 Reviewer；完整路径将理由保存到 review_decision，轻量路径在对话中说明。检查者可追查原始产物与相关证据，不只接受执行者或专家摘要；默认报告问题，保持产物原样。具体修正退回原 Executor；修正后检查受影响部分，范围扩大才扩大审查。

无须独立 Reviewer 的任务由主会话检查；轻量路径在对话中保留检查与理由，完整路径写入记录。最终完成仍须有验收证据与协调者真实工作；不要虚构 Reviewer 参与来绕过旧记录校验。旧版记录沿用旧校验，新任务用新配置。

事实不足补证；关键判断由主会话决定是否请原专家；环境错误不靠升级推理解决。一次执行加一次针对性修正，之后只在有新方案且未超过 max_attempts 时继续。失败、取消或接管如实记录，不以模型意见代替测试。

## 状态、记录与计量

本节仅用于完整记录路径。主会话维护唯一运行 JSON，保存启动配置、实际物理会话 id、工作与证据、时间和 review_decision。兼任角色只列一个物理会话；主会话 id 可用 CODEX_THREAD_ID 或已确认的当前线程 id，不凭角色名猜测。轻量任务不为填写这些字段要求子 Agent 额外调用工具。

运行起点用实际任务开始时间；只能从晚些时候采样时明确覆盖缺口。任务完成后保存检查结果与状态，仅在需要统计时调用 usage.py 读取记录内对应日志；输出是截至采样的快照，主会话最后回复尚未落盘时用量可能不完整。

若宿主或日志确证本轮 turn_id，可记录为该参与者的 usage_turn_id；该回合须在任务截止时已存在，后续复盘仅补读这个已知回合到结束，不纳入下一任务。缺少回合身份证据时保持时间边界并标不完整。

重启后先核对会话可恢复性、文件现状和已有修改；未知状态不能当成未运行。暂停停止新分发，保留产物和用量。当前模型及速度读不到则标未知，不读取登录凭据补齐。
